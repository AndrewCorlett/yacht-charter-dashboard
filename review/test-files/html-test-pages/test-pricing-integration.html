Charter Cost Pricing Integration Test

This test validates that charter costs are properly pulled from pricing settings.

Step 2: Test Yacht ID Resolution

Step 3: Test Cost Calculation

Step 4: Navigation Test Instructions

  1. Go to Settings → Pricing Configuration
  2. Change pricing for a yacht (e.g., "Calico Moon")
  3. Go to Booking Management → Create/Edit a booking
  4. Select the same yacht and dates
  5. Verify charter costs reflect your pricing changes
  6. Override the costs manually
  7. Save the booking
  8. Refresh the page and check costs persist
  9. Generate "Remaining Balance Invoice" and verify it uses updated costs
